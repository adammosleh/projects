# 🔐 نظام المصادقة المتقدم

## 📋 نظرة عامة

تم تطوير نظام مصادقة متقدم يحدد هوية المستخدم بدقة ويمنح الصلاحيات المناسبة لكل نوع.

---

## 👥 أنواع المستخدمين

### **1. العميل (Customer)**
- **كلمة المرور:** `customer123`
- **الصلاحيات:**
  - تصميم الأجزاء المختلفة
  - حفظ التصاميم
  - إرسال الطلبات للمصمم
  - عرض ملخص الطلبات
- **لا يرى:** لوحة المصمم

### **2. المصمم (Designer)**
- **كلمة المرور:** `designer123`
- **الصلاحيات:**
  - جميع صلاحيات العميل
  - الوصول لـ لوحة المصمم
  - عرض جميع طلبات العملاء
  - تحديث حالة الطلبات
  - طباعة تفاصيل الطلبات

### **3. مدير النظام (Admin)**
- **كلمة المرور:** `admin123`
- **الصلاحيات:**
  - جميع صلاحيات المصمم
  - صلاحيات إضافية مستقبلية
  - الوصول لصفحات الاختبار
  - إدارة النظام

---

## 🚀 كيفية الاستخدام

### **الخطوة 1: تسجيل الدخول**
1. افتح الصفحة الرئيسية `index.html`
2. اضغط على زر "تسجيل الدخول" (أعلى اليمين)
3. اختر نوع المستخدم من القائمة
4. أدخل كلمة المرور المناسبة
5. اختر "تذكرني" إذا أردت

### **الخطوة 2: التحقق من الهوية**
- **العملاء:** يرون واجهة عادية
- **المصممون:** يظهر زر "لوحة المصمم" في الصفحة الرئيسية
- **المدير:** يظهر زر "لوحة المصمم" + قائمة إضافية

---

## 🔧 كيف يعمل النظام

### **تحديد الهوية:**
```javascript
// نظام المصادقة الجديد
class AuthSystem {
    userTypes = {
        DESIGNER: 'designer',
        ADMIN: 'admin', 
        CUSTOMER: 'customer'
    };
}
```

### **التحقق من الصلاحيات:**
```javascript
// التحقق من الوصول لميزات المصمم
canAccessDesignerFeatures() {
    return this.currentUser && 
           (this.currentUser.type === 'designer' || this.currentUser.type === 'admin');
}
```

### **التوافق مع النظام القديم:**
```javascript
// يدعم النظام الجديد والقديم معاً
const legacyAuth = sessionStorage.getItem('designer_authenticated') === 'true';
const newAuth = window.authSystem.canAccessDesignerFeatures();
const isDesignerAuth = legacyAuth || newAuth;
```

## 🎯 واجهة المستخدم

### **قبل تسجيل الدخول:**
- زر "تسجيل الدخول" باللون الأرجواني
- لا يظهر زر لوحة المصمم

### **بعد تسجيل الدخول:**
- **العميل:** زر "عميل" باللون الأخضر
- **المصمم:** زر "مصمم" باللون الأخضر + زر لوحة المصمم
- **المدير:** زر "مدير النظام" باللون الأخضر + قائمة منسدلة

## 🛡️ ميزات الأمان

### **حماية البيانات:**
- كل مستخدم يعمل ببيانات معزولة
- لا يمكن للعملاء رؤية بيانات بعضهم
- المصمم يرى جميع الطلبات فقط

### **الجلسات:**
- **Session Storage:** للجلسات المؤقتة
- **Local Storage:** للجلسات الدائمة (مع "تذكرني")
- تسجيل خروج آمن يمسح كل البيانات

### **التحقق التلقائي:**
- فحص الهوية عند تحميل الصفحة
- تحديث الواجهة فوراً عند تسجيل الدخول/الخروج
- التوافق مع التبويبات المفتوحة
