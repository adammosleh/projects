# متجر العبايات الراقية

تطبيق ويب احترافي لبيع العبايات الأنيقة مع إمكانية التثبيت كتطبيق سطح مكتب على ويندوز.

## المميزات

### 🛍️ **واجهة متجر احترافية**
- تصميم عصري وأنيق بألوان متناسقة
- عرض المنتجات بطريقة جذابة
- نظام تصنيف للمنتجات
- بطاقات منتجات تفاعلية

### 📱 **تطبيق ويب تقدمي (PWA)**
- إمكانية التثبيت على سطح المكتب
- عمل بدون اتصال بالإنترنت
- إشعارات فورية
- تحديثات تلقائية

### 📝 **نظام طلبات متقدم**
- استمارة طلب مفصلة
- إمكانية رفع التصاميم
- اختيار المقاسات والكميات
- تأكيد فوري للطلبات

### 🎨 **تصميم مستجيب**
- يعمل على جميع الأجهزة
- تجربة مستخدم سلسة
- واجهة عربية بالكامل
- دعم RTL

## التقنيات المستخدمة

- **HTML5** - هيكل الصفحات
- **CSS3** - التصميم والتنسيق (Tailwind CSS)
- **JavaScript** - التفاعل والمنطق
- **PWA** - تطبيق ويب تقدمي
- **Service Worker** - العمل بدون اتصال

## كيفية التشغيل

1. افتح المجلد في خادم محلي (مثل Live Server)
2. افتح `index.html` في المتصفح
3. انقر على زر "تثبيت التطبيق" لإضافته إلى سطح المكتب

## الملفات الرئيسية


## التخصيص

### إضافة منتجات جديدة
```javascript
// في ملف app.js
const newProduct = {
    id: 9,
    name: "عباية جديدة",
    price: 399,
    image: "path/to/image.jpg",
    category: "عبايات عصرية",
    description: "وصف المنتج",
    badge: "جديد"
};
products.push(newProduct);
```

### تعديل الألوان
```css
/* في ملف index.html */
:root {
    --primary-color: #8b5cf6;
    --secondary-color: #7c3aed;
    --accent-color: #6d28d9;
}
```
